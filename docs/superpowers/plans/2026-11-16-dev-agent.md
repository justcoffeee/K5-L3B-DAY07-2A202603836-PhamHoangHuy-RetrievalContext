- Initially identical agent limits for all methods: 3 searches, top 3, cumulative context budget 800 characters including headers. These are experiment settings, not lab requirements.
- Final model JSON contains answer/citations/abstain. Validate IDs and explicit references; semantic quality requires separate review.
- Never send gold, answerability, expected answers or absence labels to model/retriever.
- Provider/store/protocol errors remain errors; no mocks in reported results and no fabricated quality labels.

## Review focus

5. Failed cases keep partial tool/provider trace and all known usage; no secret is logged.
